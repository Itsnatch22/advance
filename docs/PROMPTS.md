# EaziWage Hero Section Refinement

## Objective

Refine the existing EaziWage landing-page hero into a polished, modern SaaS experience inspired by the editorial composition and typography hierarchy of Notion's homepage.

The design must retain EaziWage's established visual identity, centred typography and product-frame composition.

This is a refinement of the existing hero, not a complete redesign of the landing page.

**Strictly avoid conventional split-column SaaS hero layouts.**

## 1. Hero Composition and Typography

Build a vertically centred composition with the following hierarchy:

### A. Category Eyebrow

Introduce a small category label above the main headline.

- Suggested wording: "Earned Wage Access".
- Keep it understated and visually subordinate to the headline.
- Use appropriate spacing to establish a clear separation between the eyebrow and headline.
- It should provide context without competing for attention.

### B. Main Headline

Replace the existing headline with:

"Your Money. Your Timeline."

- Maintain prominent, expressive typography.
- Preserve the established headline styling and visual treatment.
- Introduce intentional line breaks where appropriate, particularly on smaller screens.
- Ensure the headline remains the primary focal point.

### C. Supporting Description

Replace the existing core message with:

"Access up to 60% of your earned wages instantly. No loans, no interest, no waiting for payday. Just your hard-earned money when you need it most."

Refine its presentation to create a stronger relationship with the headline.

- Use comfortable line length.
- Maintain appropriate spacing.
- Ensure readability across screen sizes.
- Avoid unnecessary additional marketing copy.

### D. Email CTA

Preserve the existing email CTA and position it naturally beneath the supporting description.

The CTA must remain visually prominent without overwhelming the composition.

## 2. Visual Reference and Design Direction

Use https://www.notion.com as a design reference, particularly for:

- Editorial typography hierarchy.
- Eyebrow-to-headline relationships.
- Intentional whitespace.
- Supporting copy presentation.
- Compact informational elements.
- Overall hero composition and visual rhythm.

Do not replicate Notion's branding, layout or visual identity.

The objective is to borrow the design principles while retaining EaziWage's established visual language.

Do not introduce new colour specifications, palettes or theme changes. Follow the existing EaziWage design system and established styles consistently.

## 4. Implementation Boundaries

- Work exclusively within the existing hero section and components strictly necessary to render it.
- Preserve the existing project architecture and component conventions.
- Reuse installed dependencies and existing UI components.
- Avoid unnecessary new dependencies.
- Do not modify unrelated landing-page sections.
- Do not modify API endpoints, database logic, authentication or application routes.
- Do not introduce new interactive functionality.
- Do not modify existing responsive behaviour outside the scope of this hero refinement.

## 5. Responsive Behaviour

Ensure the composition remains intentional across desktop, tablet and mobile viewports.

- Maintain centred typography and visual hierarchy.
- Allow the headline to wrap naturally.
- Keep the benefit chips readable and appropriately spaced.
- Scale the product frame without compromising its presentation.
- Prevent horizontal overflow.
- Ensure the existing email CTA remains usable on smaller screens.
- Avoid simply shrinking the desktop layout to fit mobile.

## 7. Scope Restrictions

This task is limited to the EaziWage landing-page hero.

Do not:

- Redesign the navigation.
- Redesign the dashboard illustration.
- Introduce social-proof sections.
- Add 3D elements or external media assets.
- Introduce GSAP animations or additional animation libraries.
- Redesign other landing-page sections.
- Refactor unrelated components.
- Change existing application functionality.

Any unrelated issues discovered during implementation should be documented separately rather than addressed as part of this task.

## Expected Result

A polished EaziWage hero featuring:

1. A small earned-wage-access category eyebrow.
2. A prominent centred headline.
3. Concise supporting copy.
4. The existing functional email CTA.
5. Three understated benefit chips.
6. The existing prominent product illustration.
7. The required informational disclaimer.

The result should feel editorially polished, visually complete and distinctly EaziWage.

**The goal is to improve the presentation without increasing the implementation scope.**
